# Nawee Website

A simple, responsive German-language website for Nawee, focused on:

- English / Business English
- AI literacy
- AI-assisted learning

## GitHub Pages

1. Create a new GitHub repository, for example `nawee-website`.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the Pages URL.

## Before publishing

Replace:

- `DEINE-EMAIL@BEISPIEL.DE` in `index.html`
- `DEIN FOTO` with your professional photo
- the footer with your final legal links

For a German commercial website, add proper **Impressum** and **Datenschutzerklärung** pages before going live.

The logo is in `assets/logo.png`.
